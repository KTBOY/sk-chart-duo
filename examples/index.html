实例 1：原稿数据 + scale.exponent: 2 + defaultActive: 2，用于与 payments-fold-chart.html 效果 3 视觉对照（折痕按高差斜率自适应，见 README）。
实例 2：7 条数据 + 线性映射 + 自定义配色，验证参数化。悬停 / 点击 / 方向键均可交互。
实例 3：完整 X 轴 —— 基线 + 刻度线 + 底部语义行（阶段 / 转化率）+ X 轴标题。

悬停切换高亮列；移出后回到 defaultActive；点击列会触发 column:click 事件。
折痕观察点：相邻两列高差越大，折痕斜率越陡；超过 1:1 后折痕会从直线渐变为 S 形（水平切线进出柱顶），折面高光带同步收拢到折痕附近。点「断崖落差」「反向尖峰」看两种方向，「还原原稿数据」回到平缓漏斗。

X 轴示例：showLine + showTick + bottomLabels + title，底部留白自动扩高。
